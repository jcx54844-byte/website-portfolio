# Website portfolio

Three independent, AI-assisted static website concepts by a Shaoxing University computer science student.

- **Clearhaven** — fictional home-cleaning service landing page with a browser-only enquiry preview.
- **Relay** — fictional software landing page with an interactive task board and illustrative billing toggle.
- **Stillform** — fictional interior studio website with three pages, project filtering and detail dialogs. Spatial imagery is AI-generated.

These are portfolio exercises, not client commissions or operating businesses. There are no real bookings, payments, accounts or server-side enquiry submissions. Demo inputs are not sent or stored.

## Hosting

Static HTML, CSS and JavaScript; no build step or package installation. GitHub Pages publishes the repository root from the `main` branch. The `.nojekyll` file disables Jekyll processing.
